# Postmortem: 502 Error Storm (2025-10-21)

## Impact
- 10:12-10:35 UTC: API gateway 502 rate peaked at 18%
- Checkout conversion dropped ~7% during the window

## Root Cause
A misconfigured upstream timeout caused cascading retries:
- gateway timeout set to 200ms (too low)
- downstream p95 ~350ms during peak
- retry policy amplified load (retry storm)

## Detection & Timeline
- 10:12: alert fired: 5xx rate > 5%
- 10:16: on-call noticed upstream timeout change in config repo
- 10:22: rollback applied
- 10:35: metrics recovered

## Mitigation & Fix
- Rollback timeout config to 800ms
- Add circuit breaker for downstream dependency
- Cap retries and add jitter
